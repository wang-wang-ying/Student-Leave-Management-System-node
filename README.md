# 学生请假管理系统-node
### 1、系统功能
学生请假管理系统，采用前后端分离架构。后端基于Node.js + Express + MySQL2，前端基于Vue3 + Element Plus + ECharts，数据库使用MySQL 8.0，实现从学生管理、教师管理、班级管理、请假类型管理、请假申请、请假审批到请假统计的全流程闭环！

· 登录

· 首页（仪表盘数据统计）

· 我的请假：请假申请 | 我的请假

· 请假管理：请假审批 | 审批记录 | 请假统计

· 基础设置：学生管理 | 教师管理 | 班级管理 | 请假类型管理

· 系统管理：菜单管理 | 角色管理 | 账号管理

### 2、技术栈与工具

· 后端：Node.js + Express + MySQL

· 前端：Vue3 + Element Plus + ECharts + Pinia + Axios

· 数据库：MySQL 8.0

· 认证：JWT（jsonwebtoken）+ bcryptjs 密码加密

· 文件上传：Multer

· 构建工具：Vite 5.2
